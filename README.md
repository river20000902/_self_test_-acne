# 바르는 여드름 치료제 셀프 테스트 (프로토타입)

닥터나우 스타일 셀프테스트(`_self_test_-foot`, 손발톱 무좀)의 UX 구조를 참고해 만든
**바르는 여드름 치료제 적합성 셀프 테스트** 프로토타입입니다.

## ⚠️ DRAFT NOTICE

문항 구성 / 안전 게이트 기준(임신·수유, 경구 치료 병용, 알레르기 이력, 연령) / 중증도 임계값은
UX·로직 설계를 위한 **초안**입니다. 실제 서비스에 반영하기 전 반드시 원내 자문 전문의 및
법무/의료광고 검토를 거쳐야 합니다. 상세한 설계 배경은 별도 기획안 문서를 참고해 주세요.

## 구조

- `index.html` — 마크업
- `style.css` — 스타일 (다크 테마 + 오렌지 액센트)
- `script.js` — 상태 관리, 질문 데이터, 분기/스코어링 로직

## 로직 요약

1. **안전 게이트 4문항** — 하나라도 "예"면 중증도 점수와 무관하게 "확인 필요" 결과로 분기
2. **중증도 8문항** — 게이트 통과 시 "예" 개수(가중치 포함, B3 결절낭종 문항은 가중치 2)로
   경증 / 중등도 / 중증 3단계 판정

## 로컬 실행

정적 파일이라 별도 빌드 없이 바로 실행 가능합니다.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```
