# 내 여드름은 무슨 유형? (프로토타입)

닥터나우 스타일 셀프테스트(`_self_test_-foot`, 손발톱 무좀)의 UX 구조를 참고해 만든
**여드름 유형 자가 테스트** 프로토타입입니다. 10가지 예/아니오 질문으로 4가지 유형(A~D) 중
하나를 판정하고, 유형에 따라 꾸준한 케어 또는 피부과 비대면 진료를 권합니다.

## ⚠️ DRAFT NOTICE

문항 구성 / 유형 매핑 / 판정 로직(동점 처리 우선순위 등)은 UX 설계를 위한 **초안**입니다.
실제 서비스에 반영하기 전 반드시 원내 자문 전문의 및 법무/의료광고 검토를 거쳐야 합니다.

## 구조

- `index.html` — 마크업
- `style.css` — 스타일 (다크 테마 + 오렌지 액센트)
- `script.js` — 상태 관리, 질문 데이터, 유형 판정 로직

## 로직 요약

- 총 10문항, 전부 예/아니오로만 답변
- 각 문항은 4개 유형 중 하나에 매핑되어 있고, "네"로 답하면 해당 유형 점수 +1
  - A. 타고난 지성형 (2문항) — 꾸준한 케어 권장
  - B. 예민 호르몬형 (2문항) — 꾸준한 케어 권장
  - C. SOS형 (3문항) — 피부과 비대면 진료 권장
  - D. 만성 트러블형 (3문항) — 피부과 비대면 진료 권장
- 점수가 가장 높은 유형이 결과. 동점일 경우 **C > D > B > A** 순으로 우선
  (애매한 경우 안전하게 진료를 더 권하는 방향으로 설계)
- 전부 "아니오"면 기본값은 A(타고난 지성형)

## 로컬 실행

정적 파일이라 별도 빌드 없이 바로 실행 가능합니다.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```
